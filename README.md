## 📖 项目简介

「算法尖兵」是一款专为 **CSP-J/S（非专业级软件能力认证）初赛** 设计的理论备考训练平台。项目以军事训练营为主题包装刷题过程，通过军衔晋升、XP 积分、每日任务、错题强化等机制，帮助低龄选手（小学高年级至初中）长期坚持枯燥的初赛理论复习。

平台覆盖初赛全部笔试题型：单项选择、判断正误、阅读程序（输出预测）、完善程序（代码填空）。

## ✨ 功能特性

- **训练场**：按模块/难度筛选 + 智能组卷，即时判定与详细解析
- **挑战模式**：关卡式限时闯关，首通全额 XP、复刷递减，防刷分设计
- **错题本**：自动收集错题，基于间隔重复（1/3/7/14/30 天）的复习调度，支持三档记忆自评
- **知识图谱**：知识点掌握度动态雷达，薄弱环节自动识别并生成补强练习
- **激励系统**：XP 经验值、10 级军衔晋升、连胜 streak、每日任务，首对计分杜绝重复刷分
- **指挥中心**：学员档案、训练统计、个性化设置

## 🛠️ 技术栈

- **前端框架**：React 18 + TypeScript + Vite
- **UI**：Tailwind CSS + shadcn/ui + Framer Motion
- **路由**：React Router（HashRouter，兼容静态托管子路径）
- **状态**：自研全局单例状态总线（GameStateContext），统一计分与答题事件
- **存储**：浏览器 localStorage，无任何后端依赖

## 🚀 本地开发

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（默认 http://localhost:5173）
npm run build      # 生产构建（输出 dist/）
```

部署到 GitHub Pages 子路径时，请使用相对基座构建：

```bash
npx vite build --base=./ --outDir dist-gh
```

## 🔒 隐私与数据说明（家长须知）

- 本站为**纯前端静态应用**，没有服务器、没有账号体系、不联网上传任何数据
